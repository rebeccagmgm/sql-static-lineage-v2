# 风控重跑链路分析专题

这个目录用于承载风控任务重跑场景的调查、证据索引和结论。

专题组合三类已有能力，但不复制它们的实现：

```text
调度依赖 → 表级读写与分区影响 → SQL 静态解析 → 重跑范围与风险结论
```

## 目录约定

- `cases/<场景或任务 ID>/`：一个真实重跑案例的分析材料。
- `templates/`：经过验证后可复用的案例模板。
- 原始批量证据、生成结果和临时调试文件放在外部 evidence root 或 `tmp/`，不直接提交到本专题目录。

## 单个案例至少回答

1. 为什么需要重跑，目标业务结果是什么。
2. 调度上从哪个任务开始、依赖哪些上游、顺序是什么。
3. 表级上读写哪些物理表和分区，影响范围如何界定。
4. SQL 静态解析能证明哪些输入、表达式和写入关系。
5. 哪些结论仍是 `UNKNOWN`，需要谁或哪类运行证据确认。
6. 最小重跑链、验证点和不能自动重跑的边界。

## 边界

- 通用解析器继续位于 `src/`，复用现有 `scripts/input`、`scripts/reconcile` 等入口。
- 本专题不把调度成功、静态表名或 SQL 目标表直接当作业务结果已恢复的证据。
- 分区字段是处理范围，不改变物理表身份；无法确认的生产者、方向或业务消费保持 `UNKNOWN`。
- 第一阶段以一个真实案例闭环为目标，不先建设通用风控重跑平台。
